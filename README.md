# Whispering Wind Study Guide

A fan-made, Studio Ghibli themed study site (not affiliated with Studio Ghibli). Film stills are the official free images from https://www.ghibli.jp/works/; see the Credits page on the site.

An interactive, static study guide (GitHub Pages) covering:

- Computer systems & architecture (CS:APP)
- Python mastery
- Data structures & algorithms: Goodrich theory plus NeetCode-style pattern tracks with an in-browser judge
- SQL (runs in the browser via sql.js) and data-intensive systems (DDIA)
- Machine learning, FastAPI, MLOps
- AI engineering (Huyen), LLM internals, Hugging Face, RAG, MCP and context engineering

Everything runs client-side. Python runs in a Web Worker via [Pyodide](https://pyodide.org) (numpy, pandas and scikit-learn available), and SQL runs via [sql.js](https://sql.js.org). Progress, code and notes are saved in the browser's localStorage, and can be exported from ⚙.

## Layout

```
src/<track>/          authored content (see AUTHORING.md)
tools/build.py        validates content, runs reference solutions to compute expected outputs
docs/                 the website (GitHub Pages serves this folder)
  assets/             app.js, style.css, widgets.js, judge/ (Pyodide worker + harness.py)
  data/               generated by tools/build.py — do not edit
```

## Develop

```bash
python tools/build.py                 # build every track (must print OK)
python -m http.server 8765 --directory docs
```

Then open http://localhost:8765.

## Deploy

GitHub Pages → Settings → Pages → *Deploy from a branch* → `main` / `/docs`.
